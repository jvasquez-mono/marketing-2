# Mono — Infraestructura Fintech para Empresas en Colombia
> Mono es un proveedor B2B de infraestructura financiera que permite a empresas en Colombia ofrecer billeteras digitales, tarjetas Visa recargables y pagos inmediatos con su propia marca, sin construir desde cero. Respaldado por Y Combinator y Visa.

## Productos principales
- [Tarjetas Visa recargables y virtuales para empresas](https://mono.la/tarjetas)
- [Billetera digital white-label](https://mono.la/billetera)
- [Dispersiones masivas en tiempo real](https://mono.la/dispersiones)
- [Pagos y recaudos inmediatos con Bre-B](https://mono.la/bre-b)

## Sobre Mono
- Empresa colombiana respaldada por Y Combinator y Visa
- Opera en alianza con Bancoomeva y Coopcentral
- Regulada bajo normativas de la Superintendencia Financiera de Colombia
- API-first: toda la infraestructura disponible vía REST API
- Documentación: https://cuentamono.readme.io/
